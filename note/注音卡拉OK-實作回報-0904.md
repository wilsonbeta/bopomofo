## 2. §4 四個查證結果

### 4-1 macOS 中文語音能否直接念注音符號本身 → **可以，但只有 Meijia 可以**

我用「合成成 WAV 後逐位元組比對波形」的方式，在沒有耳朵的情況下拿到了硬證據，
結論與 Wilson 的人耳裁決一致，而且更進一步。

**證據 A：符號＝標準讀音代字，位元組完全相同。**
`say -v Meijia -o x.wav --file-format=WAVE --data-format=LEI16@22050` 產出的 PCM：

```
bpmf_b    vs han_bo    len 5483/5483 corr=1.0000 identical=True     ← ㄅ 與「玻」完全相同
bpmf_a    vs han_a     len 6341/6341 corr=1.0000 identical=True     ← ㄚ 與「啊」完全相同
bpmf_zh   vs han_zhi   len 7397/7397 corr=1.0000 identical=True     ← ㄓ 與「知」完全相同
bpmf_b    vs han_ba    len 5483/5479 corr=-0.0768 identical=False   ← ㄅ 不是念「爸」（對照組）
```

37 個符號全跑一遍，**24 個與教育部標準讀音代字位元組完全相同**：

```
ㄅ=玻 ㄆ=坡 ㄍ=哥 ㄎ=科 ㄏ=喝 ㄐ=基 ㄑ=欺 ㄒ=希 ㄓ=知 ㄔ=吃 ㄕ=詩 ㄗ=資
ㄘ=雌 ㄙ=思 ㄧ=衣 ㄨ=烏 ㄩ=迂 ㄚ=啊 ㄛ=喔 ㄞ=哀 ㄡ=歐 ㄢ=安 ㄣ=恩 ㄥ=鞥
```

剩下 13 個不同，是因為**代字帶聲調、符號念一聲**。再跟「基本音節的四個聲調」比對：

```
ㄈ -> ㄈㄛ (tone1)   ㄉ -> ㄉㄜ (tone1)   ㄊ -> ㄊㄜ (tone1)   ㄋ -> ㄋㄜ (tone1)
ㄌ -> ㄌㄜ (tone1)   ㄖ -> ㄖ  (tone1)   ㄜ -> ㄜ  (tone1)   ㄝ -> ㄝ  (tone1)
ㄟ -> ㄟ  (tone1)   ㄠ -> ㄠ  (tone1)   ㄤ -> ㄤ  (tone1)   ㄦ -> ㄦ  (tone1)
ㄇ -> ㄇㄜ (EXACT)   ← 唯一例外：念「ㄇㄜ」不是「ㄇㄛ」
```

**37/37 全部念得出正確的音節。§4-1 通過。**

**證據 B（這條是本次最重要的發現，spec 沒有預料到）：10 個 zh-TW 語音裡，9 個對注音符號輸出純靜音。**

```
Meijia_b.wav     dur=0.249s rms=5584
Meijia_bpmf3.wav dur=0.248s rms=5411          ← ㄅ / ㄅㄚˇ 正常
Eddy_b.wav       dur=0.016s rms=0.0  SILENT
Eddy_bpmf3.wav   dur=0.016s rms=0.0  SILENT   ← 但 Eddy_bo(玻)=0.745s rms=3398 正常
Flo_b.wav        dur=0.016s rms=0.0  SILENT
Sandy_b.wav      dur=0.016s rms=0.0  SILENT
```

Eddy / Flo / Sandy / Grandma / Grandpa / Reed / Rocko / Shelley 這 8 個 macOS 26 的新語音
**只念得出漢字，對注音符號輸出 0.016 秒的絕對靜音（RMS = 0）**。
而 **Chrome 的 `getVoices()` 把 Eddy 排在 zh-TW 第一個**——也就是說，
照 spec §1 只寫 `lang = 'zh-TW'`、讓瀏覽器自己挑語音，**整個程式會全程無聲**，
而且不會報任何錯（onstart / onend 照常觸發，只是沒有聲音）。

→ 實作對策：`pickVoice()` 以 `PREFERRED_VOICE_PATTERNS = [/美佳/, /Meijia/i]` **明確指名**；
挑不到時 `AUTO_FALLBACK_TO_CHAR_READING` 會自動改用讀音代字（純發音，畫面不顯示漢字）。
實跑確認 Chrome 上真的選到「美佳」（見 §4 驗收 3 的 `t3_voice`）。

### 4-2 moedict-data 格式 → **已查證，但因範圍縮減而作廢**

雖然作廢了，查證結果仍記錄如下（下載的原始檔留在 scratchpad，**沒有進 repo**）：

- repo 根目錄實際檔案與大小：`dict-concised.audio.json` 1.7 MB、`dict-revised.json.xz` 14.7 MB
  （解開 80.3 MB）、`dict-revised_bkup.json` 75.4 MB。
- `dict-revised.json` 是**陣列**，161,194 筆，每筆 `{title, heteronyms:[{bopomofo, pinyin, definitions}], stroke_count, radical}`。
  例：`{"title":"爸","heteronyms":[{"bopomofo":"ㄅㄚˋ","pinyin":"bà",...}],"stroke_count":8}`。
- `dict-concised.audio.json` 是**扁平 map**，key = `"詞.注音"`，value = 音檔 id，39,738 筆，
  其中單字詞 6,634 筆、**涵蓋 1,253 個相異音節**（正好落在 spec 預期的 1200–1300）。
  一聲不帶符號（`"媽.ㄇㄚ"`），輕聲用**前綴** `˙`（`"吔.˙ㄧㄝ"`）——與 spec §3 假設的字尾式不同。
- 若當初要做表，我會用 `dict-concised.audio.json`（它本身就是「簡編本＝常用詞」，天然的常用字過濾）。
  但代表字挑法有坑：用「該字在簡編本詞條中出現次數」當字頻 proxy，`ㄅㄚˋ` 會挑到「把(36)」而不是「爸(4)」，
  `ㄋㄧˇ` 會挑到「擬(17)」而不是「你(10)」——對小朋友是壞選擇。**這條路需要額外的兒童常用字加權清單才會對。**
  現在整段作廢，這個坑不用踩了。

## 3. 實作要點

### 3-1 可切換常數（都在 `src/lib/config.ts`）

| 常數 | 預設 | 作用 |
|---|---|---|
| `SYMBOL_READING_MODE` | `'symbol'` | `'symbol'` 直接念注音符號；`'char'` 改念教育部讀音代字 |
| `AUTO_FALLBACK_TO_CHAR_READING` | `true` | 挑不到 Meijia 時自動退回代字讀音，避免整個 app 無聲 |
| `SPEAK_ON_KEY` | `true` | 敲鍵當下立刻念一次那個符號（單 utterance、不高亮） |
| `PREFERRED_VOICE_PATTERNS` | `[/美佳/, /Meijia/i]` | 語音偏好順序 |
| `UTTERANCE_TIMEOUT_*` | 1500 / 6000 / 700ms per char | `onend` 沒回來時的保險絲 |
| `TOKEN_GAP_MS` | 180 | token 之間的空隙 |
| `ANIM_MS` | 260 | 動畫長度（≤300ms） |

### 3-2 互動設計 5 條（照裁定實作）

1. 四類固定顏色：聲母 `#E8590C` 橘／介音 `#2F9E44` 綠／韻母 `#1971C2` 藍／聲調 `#9C36B5` 紫；
   空格為 `#C9CDD4` **淡虛線框佔位**。螢幕鍵盤按鍵也用同一套顏色。
2. 敲鍵即念：`insert()` 內呼叫 `echoSymbol()`，單 utterance、不觸發高亮，`SPEAK_ON_KEY` 可關。
3. 整字 token：`kind: 'whole'`，四格同時 `highlighted`，外層 board `scale [1,1.08,1]` 脈動
   ＋ `box-shadow` 黃色外框發光；其餘 token 只亮單格（`scale 1.4` ＋ 換色）。
4. 念完整串後 board 做 `y: [0,-14,0]` 輕微彈跳，`ANIM_MS + 60` 後自動復原。
5. 全部 framer-motion，每段 260ms，無粒子、無音效檔。

### 3-3 兩個實作上的取捨（需要你知道）

**(a) 輕聲的 `˙` 放字尾，不放字首。** 教育部辭典寫法是前綴（`˙ㄅㄚ`），但實測 Meijia：

```
ㄅㄚ   dur=0.248 rms=5485
˙ㄅㄚ  dur=0.248 rms=5485   ← 前綴被引擎忽略，念成一聲
ㄅㄚ˙  dur=0.179 rms=4533   ← 明顯較短，是真的輕聲
```

為了發音正確，`toSyllable()` 用字尾式。這與辭典慣例不同，但畫面上聲調本來就在右格，視覺上一致。

**(b) 一聲在畫面上顯示 `ˉ`（U+02C9）。** 正統注音一聲不標符號，但格子需要看得見的回饋，
所以按 Space 會在聲調格顯示 `ˉ`；組成整字字串時會被拿掉（`ㄅㄚˉ` → `ㄅㄚ`）。
`ˉ` 不是漢字，不違反「不出現中文字」。
