# 注音卡拉OK 第三期 — 任務 spec（0904 深夜，Opus partner）

> 母題：注音卡拉 OK；第二期已上線 `04235f6`。本期是 Wilson 看過畫面後的五點回饋，掛同一條線。
> **主線一句話**：版面會呼吸＋對齊；卡片變成像課本裡的完整注音字；整列播放改成「像念句子」；不合法的音節不准存。

## 0. 結案判準

「三欄各自有淡淡的底，左右拉開不擠；海報四區左邊齊、字格與按鈕左邊齊；卡片就是一個個小小的注音字，沒有格子框；按 ▶▶ 聽到的是一句話一氣呵成，不是逐符號拆念；拼一個 ㄈㄞ 想存，字格搖頭、存不進去。」

## 1. 版面（三項，機械改動）

1. **會呼吸**：外層改成 `maxW ≈ 1400px` 置中、`justify="space-between"`，三欄之間最小 gap 40px；窄螢幕仍上下堆疊。
2. **三欄底色**：每欄包一層 panel——很淡的底（例：`rgba(0,0,0,0.03)` 或各欄取一點點自己主色的 tint ≤ 0.04）、圓角 24px、padding 20px。目的是「心理上的功能區隔暗示」，**要看得出來但不能搶戲**。
3. **對齊**：
   - 海報模式（右欄）：四個 zone **等寬、左緣對齊**，zone 內按鍵從左排起；現在介音區縮成一小塊置中、聲調區又比較寬，要齊。
   - 中欄：字格與底下三顆按鈕 **左緣對齊**（`align="flex-start"`），不再置中。

## 2. 卡片改成「完整的注音字」

- **拿掉迷你四格的框**。卡片內只畫符號本身：上中下**垂直堆疊**、聲調在右側偏中（課本排法）；**空格不佔位**（ㄇㄠ 就是兩個符號疊著，不留虛線空位）。一聲不顯示（課本一聲不標；`ˉ` 只在主字格當輸入回饋）。
- 字要夠大（符號約 34–40px），四類顏色沿用，讓小朋友看得出聲母／韻母。
- 卡片外框保留（點擊／拖曳目標、選中／播放中狀態要看得到），但改得更輕：1.5–2px 邊、圓角 16px、白底。× 刪除鈕保留在角落。
- 卡片高度隨內容（兩符號的卡比三符號的矮一點沒關係），寬度固定。

## 3. 整列播放改成「念句子」

現況：每張卡走完整序列（符號→聲調→整字），像上課。Wilson 要的是**像講故事一句話念完**。

- **▶▶ 的行為改為**：把整列卡片的**代讀漢字**（`SYLLABLE_READING[syllable]`）串成一個字串，**一個 utterance 念完**，讓引擎自己處理句子韻律（連讀、變調）。
- **卡片同步高亮**：每張卡對應字串裡**剛好一個字**，所以 `onboundary` 的 `charIndex` 可以直接對到卡片 index。
  - ★不確定處 A：`onboundary` 在 macOS Chrome／Safari 對中文、對 Meijia 到底會不會觸發、charIndex 是不是逐字——**先寫最小 html 實測**。會觸發 → 逐卡高亮；不觸發 → 退回「整列一起淡淡發光＋字格不動」，並在回報說明。**不要用估時長來假裝同步。**
  - 高亮的同時中欄字格要不要跟著換？→ 若逐卡高亮可行，字格跟著換（顯示當前卡的四格，但**不做**逐符號放大）；若不可行，字格不動。
- 單張點卡片的行為**不變**（仍是符號→聲調→整字的學習序列）。
- 播放中再按 ▶▶＝停（`cancel()`），停止後無殘留高亮。
- 句尾可加一個句號「。」給引擎當語氣結尾（純送引擎、畫面不顯示）；實測有沒有差再決定。

## 4. 合法性：不合法的音節不准存

- 定義：**`SYLLABLE_READING` 表裡查得到＝合法**（1250 個音節）。這張表就是「國語有這個音」的判準，不另寫規則。
- **儲存**（鈕／Cmd+S）遇到不合法：不存，字格做一次**左右搖頭**（`x: [0,-10,10,-6,6,0]`，≤ 300ms）＋ 邊框短暫變紅；不彈任何文字。
- **匯入**：任何一張卡不合法 → 整份拒絕（沿用紅框），deck 不變。
- **單張播放**（Enter／點卡）不擋：小朋友仍可聽到不合法組合會變成逐符號念，這本身是回饋。
- 純聲調、純空格（沒有任何聲韻符號）也視為不合法。
- 已存在 localStorage 裡的舊卡若不合法（第二期之前存的）：載入時**保留但標示**（卡片邊框紅、整列播放時跳過）——不要默默刪小朋友的資料。

## 5. 已知不確定處（★先查證）

A. `onboundary` 對 zh-TW／Meijia 的行為（見 §3）。
B. 一個 utterance 串多字時，Meijia 對「單音字串成的句子」會不會亂讀（例如把兩個代讀字合成詞讀成別的音）。抽 5 組實測 PCM：句子整段 vs 各字單獨 concat，時長與波形是否合理；發現亂讀就回報，我們再決定要不要在字間插「，」或全形空白。
C. 卡片拿掉框後，拖曳感應區是否還好抓（PointerSensor distance 5 是否要調）。

3. 存 ㄇㄠ、ㄇㄚ、ㄇㄧˋ 三張：卡片內無虛線框、空格不佔位、一聲無符號。
4. ▶▶：攔到**單一** utterance、文字＝三個代讀字（＋句號若採用）；若 onboundary 可用，三張卡依序高亮；停止後無殘留。
