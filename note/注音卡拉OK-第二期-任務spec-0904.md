# 注音卡拉OK 第二期 — 任務 spec（0904，Opus partner）

> 母題：注音卡拉 OK（第一期已上線 `9c40c49`＋版面 `5846696`）。本期是 Wilson 提的三個延伸，掛同一條線。
> **主線一句話**：右欄可切「鍵盤／海報」兩種排法；把拼好的音存成卡片排在最左欄，小朋友點卡片就念、拖曳排序後可整列連念；卡片可匯出／匯入 JSON。

## 0. 結案判準

「小孩拼好 ㄅㄚˇ 按儲存 → 左邊出現一張卡；再拼幾個；拖一拖順序；按整列播放，聽到一張一張念、卡片跟著亮。關掉瀏覽器再開卡還在；按匯出拿到 json，換台電腦匯入一樣的卡。」

## 1. 不變的前提

- 選型不變（Next 16 / Chakra v3 / framer-motion / 4 空格）。拖曳用 **@dnd-kit**（`@dnd-kit/core` + `@dnd-kit/sortable` + `@dnd-kit/utilities`，Wilson 的 hhg-oms 也用這套）。
- **畫面仍不出現中文字**：所有按鈕用圖示（inline SVG 或 react-icons 皆可）。
- 沒有後端、沒有 DB。持久化＝ `localStorage`（自動）＋ JSON 匯出／匯入（手動）。
- 第一期的發聲／高亮機制（`playSequence`、一 token 一 utterance）**直接複用**，不重寫。

## 2. 三欄版面

寬螢幕（≥ lg）三欄：**左＝卡片列表｜中＝字格＋按鈕｜右＝鍵盤／海報**。窄螢幕上下堆疊：字格 → 鍵盤 → 列表。
中欄維持第一期樣子，只多一顆「儲存」鈕。

## 3. 右欄：鍵盤模式 ⇄ 海報模式

- 右欄頂端一顆切換（segmented 兩段，圖示：鍵盤／格狀海報），狀態存 `localStorage`。
- **鍵盤模式**＝現有 `OnScreenKeyboard`（大千式排列），不動。
- **海報模式**＝國語課本順序、依用途分區、聲調獨立一區。排法（每行一組，行與行間距略大）：
  ```
  聲母  ㄅㄆㄇㄈ ／ ㄉㄊㄋㄌ ／ ㄍㄎㄏ ／ ㄐㄑㄒ ／ ㄓㄔㄕㄖ ／ ㄗㄘㄙ
  介音  ㄧㄨㄩ
  韻母  ㄚㄛㄜㄝ ／ ㄞㄟㄠㄡ ／ ㄢㄣㄤㄥ ／ ㄦ
  聲調  ˉ ˊ ˇ ˋ ˙   （ˉ＝一聲，與字格顯示一致）
  ```
  四區各用既有 `SLOT_COLOR`；區與區之間用淡底色塊或細分隔線區隔，**不用文字標題**（可用一小色塊當區標）。
- 兩種模式點按行為相同（呼叫同一個 `onPress`，敲鍵即念照舊）。實體鍵盤在任何模式都可用。

## 4. 左欄：卡片列表

### 4.1 資料
```ts
interface Card { id: string; cells: Cells }          // cells 同第一期
interface Deck { version: 1; cards: Card[] }
```
- `localStorage` key `bopomofo.deck.v1`，每次變動即寫；載入時壞資料（parse 失敗／shape 不對）就當空 deck，不 crash。

### 4.2 卡片外觀
- 一張卡＝迷你版四格（上中下＋右聲調，同色系、縮小約 0.35），空格淡虛線。直排一列，寬約 120px。
- 卡片狀態：一般／**選中**（粗框）／**播放中**（同字格的高亮色＋輕微放大）。

### 4.3 操作（全部圖示，無文字）
| 動作 | 怎麼觸發 | 行為 |
|---|---|---|
| 新增 | 中欄「儲存」鈕（`Cmd/Ctrl+S` 同義）且**沒有選中卡片** | 把字格四格存成新卡片，加在列表**最後**；字格不清空 |
| 修改 | 點卡片＝載入字格並選中 → 改字格 → 再按儲存 | 覆寫該卡；儲存後仍保持選中 |
| 取消選中 | 按 Esc（同時全清字格）或再點同一張卡 | 回到「無選中」，之後儲存就是新增 |
| 單張播放 | 點卡片 | 載入字格 → 選中 → **立刻用第一期序列念一次**（符號→聲調→整字，字格同步高亮） |
| 刪除 | 卡片右上角小 × | 直接刪，不確認（小朋友場景，少一步）；若刪的是選中卡則取消選中 |
| 拖曳排序 | 拖卡片本體 | @dnd-kit sortable，垂直；拖曳中卡片半透明 |
| 整列播放 | 左欄頂端「▶▶」鈕（`Shift+Enter` 同義） | 依目前順序逐張：載入字格 → 卡片亮 → 念完整序列 → 下一張；卡間停 `DECK_GAP_MS`（config，預設 500）。播放中再按＝停止。播放中禁用拖曳與刪除 |
| 匯出 | 左欄底部「⤓」鈕 | 下載 `bopomofo-deck-YYYYMMDD.json`（`Deck` 原樣，pretty print） |
| 匯入 | 左欄底部「⤒」鈕 → `<input type=file accept=.json>` | 驗 `version===1` 且每張 `cells` 四欄值皆合法符號或 null；**合法就整份取代**現有 deck；不合法就閃紅框 600ms，什麼都不改 |

- 空字格按儲存＝無動作。
- 儲存成功卡片做一次 `scale [1,1.12,1]` 的回饋（≤300ms）。

## 5. 已知不確定處（★partner 先查證）

1. Next 16 + React 19 下 `@dnd-kit/sortable` 最新版是否相容（peer deps／StrictMode 雙次 mount）；不相容就報上來討論，不要自己換庫。
2. 整列播放時「卡片高亮」與「字格高亮」兩套狀態並存，確認 `active`／`playing` 的 state 不會互相打架（尤其 cancel 後殘留高亮）。
3. `Cmd+S` 在瀏覽器預設是存網頁，要 `preventDefault`；確認 Safari/Chrome 都攔得到。
4. 檔案下載在 Safari 是否需要 `<a download>` 加到 DOM 才會觸發。

## 6. 驗收條件（實跑、附證據）

1. `yarn build` 過；`yarn dev` 開頁無 console error。
2. 切海報模式：四區排列如 §3、顏色正確；重整頁面模式保留。海報模式點 ㄅ → 上格出現 ㄅ 且即念。
3. 拼 `1 8 3` 按儲存 → 左欄出現一張迷你 ㄅㄚˇ 卡；再拼 `t j ; 4` 儲存 → 第二張。重整頁面兩張都在。
4. 點第一張卡 → 字格變回 ㄅㄚˇ、卡片選中、聽到整段序列；改成 `4`（ˋ）再按儲存 → 第一張卡變 ㄅㄚˋ，仍兩張。
5. 拖第二張到第一張前 → 順序對調；重整後順序保留。
6. 按整列播放 → 依新順序兩張各念一遍、播放到哪張哪張亮、字格同步；中途再按＝停、無殘留高亮。
7. 刪第一張 → 剩一張。匯出 → 檔名與內容正確。清空後匯入剛才的檔 → 卡回來；匯入一個壞 json → 紅框、deck 不變。
8. 畫面 DOM 無任何漢字（沿用第一期的 `noChineseInDom` 檢查）。
9. Chrome 跑完 1–8；Safari 至少人工開頁確認版面與匯出（自動化不開權限，標「需人工」）。
