# 注音卡拉OK — 任務 spec（0904，Opus partner）

> 母題：Wilson 要一個給小朋友在**本機**玩的注音練習小程式。零付費第三方、可離線。
> **主線一句話**：小朋友敲鍵盤把注音填進「上／中／下」三格＋右邊聲調格，按「念」之後，
> 程式**逐符號念出「ㄅ、ㄚ、三聲、爸」**，每念到哪個符號畫面上那個符號就**放大＋變色**（卡拉 OK 感）。

## 0. 結案判準（用戶會用哪句話判成不成）

「我小孩坐下來，在鍵盤上敲 `1 8 3` 再按 Enter，聽到清楚的『ㄅ、ㄚ、三聲、爸』，畫面跟著一格一格亮。」
撞不上這句＝沒完成，不管其他功能做了多少。**音要對、要同步、要清楚**——UI 花俏度是次要。

## 1. 技術選型（已裁，不重開）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 框架 | Next.js 16 + React 19 + TypeScript，`yarn dev` | 對齊 Wilson 習慣的 hhg-oms 開發模式 |
| UI | Chakra UI v3 + framer-motion | 同上；膨脹／變色動畫用 framer-motion |
| 發聲 | **瀏覽器 Web Speech API（`speechSynthesis`）**，`lang = 'zh-TW'` | 零安裝、零費用、離線；macOS Safari/Chrome 直接用系統 zh_TW 語音（本機已有 Meijia 等 10 個 zh_TW 聲音，`say -v '?'` 實查） |
| 整字資料 | 注音音節 → 代表漢字 的靜態 JSON（build-time 生成） | 見 §3 |
| 縮排 | 4 空格（同 hhg-oms） | |

不用 eSpeak／Piper／雲端 TTS。整個 app 只跑 `yarn dev`，不需要後端 API、不需要 DB。

## 2. 互動規格

### 2.1 畫面
- 中央一個大「字格」：**上／中／下三格垂直排列**，右側一個窄的**聲調格**。像國語課本的注音格。
- 三格的語意固定：**上＝聲母、中＝介音（ㄧㄨㄩ）、下＝韻母**。
- 底下一顆大按鈕「念」（Enter 同義）。
- 下方顯示整字結果：找得到字就顯示大字（例：爸）；找不到顯示「沒有這個字」（不是錯誤，是教學回饋）。
- 給小朋友用：字要大、對比要高、按鈕要好按；不要小字說明、不要 modal。

### 2.2 鍵盤 → 注音（標準注音鍵盤配置，依 `event.code`/實體鍵位對應，不依輸入法）
```
1ㄅ 2ㄉ 3ˇ  4ˋ  5ㄓ 6ˊ  7˙  8ㄚ 9ㄞ 0ㄢ -ㄦ
qㄆ wㄊ eㄍ rㄐ tㄔ yㄗ uㄧ iㄛ oㄟ pㄣ
aㄇ sㄋ dㄎ fㄑ gㄕ hㄘ jㄨ kㄜ lㄠ ;ㄤ
zㄈ xㄌ cㄏ vㄒ bㄖ nㄙ mㄩ ,ㄝ .ㄡ /ㄥ
Space＝一聲　Enter＝念　Backspace＝清最後一格　Esc＝全清
```
- 符號依**類別自動落格**：聲母→上、介音→中、韻母→下、聲調→右。同類再敲一次＝**取代**該格。
- Backspace 清除順序：聲調 → 下 → 中 → 上（最後填的先清）。
- 也要能用滑鼠／觸控點畫面上的注音鍵盤（可簡化為一排排按鈕），供不熟鍵盤的孩子用。

### 2.3 「念」的行為（卡拉 OK 核心）
把當下四格轉成一串 **token 序列**，**每個 token 一個獨立 `SpeechSynthesisUtterance`，依序播**：
```
[上符號] → [中符號] → [下符號] → [聲調詞] → [整字]
例：ㄅ → ㄚ → 三聲 → 爸
```
- 空格跳過。聲調詞：一聲／二聲／三聲／四聲／輕聲；**沒填聲調視為一聲並照念「一聲」**。
- 整字找不到 → 略過整字 token，畫面顯示「沒有這個字」。
- **同步機制**：每個 utterance 的 `onstart` 觸發該 token 的高亮（scale ≈ 1.4 + 換色，framer-motion），`onend` 復原。
  **不要用 `onboundary`**（中文語音支援不穩），一 token 一 utterance 就是為了拿到可靠的時間點。
- 播放中再按念＝先 `speechSynthesis.cancel()` 再重播。
- 首次發聲必須在 user gesture（按鈕／Enter）之後觸發，Safari 才放行。

## 3. 資料：注音音節 → 代表漢字（★0904 Wilson 裁：整段作廢，app 不出現中文字；發音直接送注音字串）

- 來源優先序：**g0v moedict-data**（教育部辭典、台灣讀音、欄位直接有注音）> Unicode Unihan `kMandarin`（拼音、偏大陸讀音，備援）。
- 產出：`data/syllables.json`，shape `{ "ㄅㄚˋ": "爸", "ㄅㄚ": "八", ... }`（key＝正規化注音字串，一聲**不帶**符號；聲調符號用 ˊ ˇ ˋ ˙）。
- 代表字挑法：**單字詞、常用字優先**（小朋友認得的字）。若來源沒有字頻，退而用「單字詞中筆畫少者」或內建一份常用字清單加權——**選了哪個做法要寫進回報**。
- 生成腳本放 `scripts/build-syllables.ts`，一次性跑；產物 JSON **進 repo**，runtime 不依賴網路。
- 表大小預期 ~1200–1300 個音節。

## 4. 已知不確定處（★partner 查證最勤的段）

1. **macOS 中文語音能否直接念注音符號本身**（「ㄅ」念成 /bo/）。
   我實測 `say -v Meijia "ㄅ"` 有 0.25s 音訊輸出、`"ㄈㄞ"` 0.57s、`"☃"` 2.3s（明顯是念符號名），但**我沒有耳朵，無法確認念的內容**。
   已請 Wilson 用耳朵驗。**實作規約**：符號 token 的文字要走一個可切換的 `symbolReading` 對照表——
   預設直接送符號本身；並內建**備援表**（教育部標準注音讀音代字：ㄅ玻 ㄆ坡 ㄇ摸 ㄈ佛 ㄉ得 ㄊ特 ㄋ訥 ㄌ勒 ㄍ哥 ㄎ科 ㄏ喝 ㄐ基 ㄑ欺 ㄒ希 ㄓ知 ㄔ吃 ㄕ詩 ㄖ日 ㄗ資 ㄘ雌 ㄙ思 ㄧ衣 ㄨ烏 ㄩ迂 ㄚ啊 ㄛ喔 ㄜ鵝 ㄝ耶 ㄞ哀 ㄟ欸 ㄠ熬 ㄡ歐 ㄢ安 ㄣ恩 ㄤ昂 ㄥ鞥 ㄦ兒），一個常數切換。
2. **moedict-data 的檔案格式與體積**：repo 根目錄看到 `dict-concised.audio.json`、`dict-revised.json.xz`、`dict_revised/` 等，**哪個檔有注音欄、shape 長怎樣，我沒讀過**，你要實際下載開來看再決定。
   體積大的話 build script 只在本機跑一次，不要把原始辭典檔進 repo。
3. **瀏覽器語音的實際可用性**：Chrome 的 `getVoices()` 在 macOS 上會不會列出 zh_TW 系統語音、`onstart/onend` 在連續多個 utterance 時會不會漏事件——**要實跑驗**，不是查文件。若某瀏覽器 `onend` 不可靠，備援用 `onend` + timeout 雙保險。
4. 標準注音鍵盤配置表我是憑記憶寫的，**對照一次**（macOS 系統偏好設定→鍵盤→注音，或維基「注音輸入法」鍵位圖）。

## 5. 驗收條件（4a 驗收 partner 逐條實跑）

1. `yarn dev` 起得來，開 `http://localhost:3000` 無 console error。
2. 敲 `1 8 3`：上格ㄅ、下格ㄚ、聲調格ˇ，中格空。
3. 按 Enter：依序聽到 4 段語音，畫面依序高亮 ㄅ → ㄚ → ˇ → 爸；整字區顯示「爸」。
4. 敲 `z 9`（ㄈㄞ）按 Enter：念 ㄈ、ㄞ、一聲，整字區顯示「沒有這個字」，不 crash。
5. 敲 `2 8` 再敲 `1`：上格由ㄉ變ㄅ（同類取代）。Backspace 一次：ㄚ 消失、ㄅ 留著（清除順序）。
6. 播放中連按 Enter 兩次不會疊音。
7. `data/syllables.json` 存在、≥1200 筆、`ㄅㄚˋ→爸`、`ㄇㄚ→媽`（或同等常用字）抽查合理。
8. Safari 與 Chrome 各跑一次 1–4。
